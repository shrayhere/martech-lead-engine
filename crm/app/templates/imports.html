Synchronization mode

Insert only

Add new contacts. Existing records (same email) are never modified.

Update existing

Update matching contacts only. Empty CSV cells keep current values. No new contacts.

Upsert

Insert new contacts and update existing ones. Recommended for regular syncs.

Safety rules: exact email matches are treated as the same person; matches by phone or name + company are never merged automatically. They go to the duplicate review queue. Records missing from the CSV are never deleted. The import runs in one database transaction and is rolled back completely if anything fails.
